使用说明与处理范围

选择文件 → 点击「开始格式化」→ 查看检查结果 → 下载全部 ZIP。解压到单独文件夹，文件名保持原名；如果 HTML 引用了共享 CSS、图片或脚本，请保持原有相对目录结构。

工具只调整可验证的空白字符。JavaScript 通过词法单元和语法树对比；CSS 对比属性、取值、选择器和注释；识别到 Vue 3 挂载模板时，对比整理前后的编译结果。普通静态 HTML 的元素间空白保留原样，避免改变行内布局或继承的 white-space 显示。

支持 UTF-8、带 BOM 的 UTF-8 / UTF-16 LE / UTF-16 BE，保留原编码及 BOM。语法错误、动态挂载入口、自定义 Vue 编译配置或无法验证的区域会保留原样。Vue 模板检查使用内置的 Vue 3.5.24 编译器。

导入文件只作为文本读取，工具不会运行其中的脚本。页面刷新或关闭后，当前文件列表会清空。
